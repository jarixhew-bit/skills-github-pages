# 健身示范用人体模型

- `fitness-female.glb`：女性健身体型＋深色运动内衣与短裤，骨架用 Mixamo 命名（mixamorigHips…）。
  由 `tools/build-fitness-muscle-model.py`（female 参数）从 MakeHuman 社区 MPFB2 素材生成。
- 授权：MPFB2 的人体网格、体型变形与骨架素材是 **CC0 1.0**（https://github.com/makehumancommunity/mpfb2 ，
  见该仓库 LICENSE.ASSETS.md），可以公开再发布，所以模型本身也放进仓库，渲染不再依赖临时下载。
- 对照：旧动图用的 Mixamo X Bot 授权不允许转发原档，所以那个模型从未进仓库。
