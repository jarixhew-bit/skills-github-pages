名字保持默认就好。按完回到桌面，会多一个新图标——以后每天都点它，不要再用 Safari 开。Keep the default name. Go back to your Home Screen and you will see a new icon — use that one from now on, not Safari.

常见问题If something goes wrong

面板里找不到「加到主屏幕」I cannot find “Add to Home Screen”
两个原因：一是那一列没滑到底；二是你不是用 Safari 开的（微信、Chrome 里没有这个功能）。把网址复制出来，用 Safari 重开一次。Two reasons: you have not scrolled that list to the bottom, or you are not in Safari (Chrome and in-app browsers do not have it). Copy the address and open it in Safari.
还要再填一次访问码吗？Do I have to enter the access code again?
要，但只要一次。新图标是一个全新的 App，第一次打开会让你填访问码，填完就不用再填了。忘了就问 YANG。Yes, once. The new icon is a fresh app, so it asks for the access code the first time and then remembers it. Ask YANG if you forgot it.
装好了要怎么确认？How do I know it worked?
点新图标打开，上面没有网址栏、没有底下那排 Safari 按钮，整页满屏，就对了。Open the new icon: no address bar at the top, no Safari toolbar at the bottom, the page fills the whole screen. That is it.

装好后每天打开新图标即可看到最新行程和账单。Use the new icon every day to see the latest itinerary and bills.
