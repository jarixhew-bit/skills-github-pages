每日自动上线签到

手机端脚本 · 安卓 · 不用电脑、不用 root · 按本页从上往下做一遍即可

先说风险，你决定要不要做
  • 几乎所有手游的服务条款都禁止脚本和模拟点击，被判定为使用外挂可能封号。
  • 大厂游戏（腾讯、米哈游、网易等）普遍装了反外挂检测，风险明显更高。
  • 每天只做签到领奖这种低强度操作，被抓的概率不高，但不等于零。
  • 如果这个账号你充过不少钱，建议先想清楚，或者先拿小号试一个月。

为什么只能是「模拟点击」，不能做成真正的机器人

真正的机器人（挂在服务器上、手机关机也能跑）需要游戏方提供接口。手游基本都不提供， 只有网页游戏和少数有官方 API 的游戏可以。所以对手游而言，唯一可行的路是： 在你自己的手机上，让一个程序帮你看屏幕、帮你点。这也是本页做的事。

因为它靠「看屏幕」工作，所以有两条硬性前提：手机要开着、屏幕要亮着（跑的那几分钟）。 跑完会自动回桌面。

需要装什么

AutoX.js（本页脚本用的就是它）

一个能跑 JavaScript 的安卓自动化工具，支持截图找图，免费开源。 它不在 Google Play 上，要去 GitHub 下载安装包：

github.com/kkevsekk1/AutoX/releases

在 Releases 页面找最新版的 .apk 文件下载（通常叫 autoxjs-v7.x.x.apk）。 安装时安卓会提示「来自未知来源」，允许即可。另有一个持续维护的分支 AutoJs6，用法基本一样，两个选一个即可。

如果你不想装 APK：Macrorify（Google Play 有）

Play 商店里能直接装、同样支持图像识别的替代品是 Macrorify - Image Auto Clicker。 它是图形界面操作（录制动作、设定「看到这张图就点」），不写代码，上手更简单。

代价是：本页的三个脚本在它上面用不了，逻辑要你自己在它的界面里点出来； 免费版对宏的长度和定时有限制。适合「不想碰代码」的情况。

两种跑法：手机上跑，还是电脑上跑

底下的步骤两种都适用，因为模拟器本身就是安卓——同样三个脚本， 搬进模拟器一行都不用改。差别只在跑在哪台机器上：

手机上跑电脑模拟器里跑（更省心）
要开着的东西手机，且那几分钟屏幕要亮电脑
会不会占用你会，跑的时候手机不能用不会，你该干嘛干嘛
锁屏麻烦有密码锁就解不开没有锁屏这回事
模板图会不会失效换手机、改显示大小就得重截分辨率你自己定死，永久有效
风险游戏检测脚本游戏检测脚本 ＋ 检测模拟器

真要「全自动、完全不碰手机」，选电脑那一栏。多出来的那点风险是： 有些游戏会认出模拟器环境。暗影紀元这类休闲挂机游戏一般不查， 但不保证。

电脑方案要多做的三件事

  1. 装模拟器：雷电模拟器 LDPlayer 或 网易 MuMu，都免费。装好后在里面登你的 Google 账号， 用 Play 商店装 暗影紀元。 进游戏后先把画质、分辨率设定好就别再改了——模板图是按这个分辨率截的。
  2. 模拟器里装 AutoX.js：把下载好的 APK 文件直接拖进模拟器窗口就会自动安装。 之后的步骤（开无障碍、开截图权限、截图裁模板、设定时）跟手机完全一样，照着下面做。
  3. 让电脑到点自动开模拟器：Windows 搜索「任务计划程序」→ 创建基本任务 → 每天某个时间 → 启动程序 → 选模拟器的 .exe。模拟器开机后， AutoX.js 里设的定时任务会接着把脚本跑起来。 雷电和 MuMu 也都自带「定时启动」功能，用哪个都行。
电脑方案有个手机没有的好处值得说一下：模拟器窗口的分辨率是你定死的， 不会像手机那样因为系统更新、改字体大小而变。模板图截一次就能一直用， 自检里那条「分辨率对不上」的警告基本不会再出现。

三个脚本各是做什么的

  • capture-helper.js —— 准备工具。帮你查出游戏包名、连续截图、 测试某张模板图找不找得到。第一次配置时用。
  • selftest.js —— 自检。检查权限、截图、找图功能是否正常。 配置前跑一次；以后哪天脚本失灵了，先跑它，它会直接告诉你坏在哪一层。
  • daily-login.js —— 正式脚本。每天定时跑的就是它。 你只需要改它开头的【配置区】。

1装好 AutoX.js，开两个权限

这两个权限缺一不可，缺了脚本要么看不见屏幕、要么点不动：

  1. 无障碍服务：手机 设置 → 无障碍（辅助功能）→ 找到 AutoX.js → 打开。 没有它，脚本能看到屏幕但点不动。
  2. 截图权限：脚本第一次运行时会弹「开始截屏/投射」的系统框，点 立即开始。建议勾上「不再询问」，否则每天都要手动点一次，定时就没意义了。
另外去 手机设置 → 电池 → 找到 AutoX.js → 设成不受限制 / 允许后台运行。 不设的话系统会在半夜把它杀掉，定时任务就不会触发。这是定时失灵最常见的原因。

2把脚本放进手机

用手机浏览器打开下面三个链接，每个都是纯文字。全选 → 复制， 回到 AutoX.js 点「＋ 新建脚本」，粘贴进去，存成对应的文件名。 这比下载文件再找文件管理器省事。

  • capture-helper.js（准备工具）
  • selftest.js（自检）
  • daily-login.js（正式脚本）

也可以长按链接选「下载链接」存成文件，再放进 AutoX.js 的脚本目录 （一般是 /sdcard/脚本/）。两种方式效果一样。

脚本会用到手机上这几个文件夹，它自己会建，你只要知道东西在哪：

路径放什么
/sdcard/game-bot/tpl/模板小图（你裁出来的按钮图，最重要）
/sdcard/game-bot/screens/连拍的整屏截图（用来裁模板）
/sdcard/game-bot/shots/失败时自动存下的现场截图
/sdcard/game-bot/log.txt运行日志，每天发生了什么都在这

3跑 capture-helper.js，查出游戏包名

运行 capture-helper.js，选菜单第 1 项「查游戏包名」， 输入游戏名的一部分，从列表里选中你的游戏。它会把包名显示出来并复制到剪贴板， 形如 com.company.gamename。记下来，等下要填。

4连拍截图，裁出模板小图

还是 capture-helper.js，选第 2 项「连续截图」。 点确定后有 8 秒切回游戏，然后你就正常手动做一遍每日签到， 它会每 3 秒拍一张，把整个流程拍下来。

拍完去相册（或任何图片编辑 App）打开 /sdcard/game-bot/screens/ 里的截图， 把你要脚本点的按钮单独裁出来，存成小图放进 /sdcard/game-bot/tpl/。

裁图是整件事成败的关键，就这一条要记牢：
  • 只裁按钮本身，裁小一点、裁干净一点。
  • 千万别把会变的东西裁进去：倒计时、剩余次数、红点数字、 玩家头像、会飘动的特效、渐变的背景。今天长这样明天长那样，脚本就永远找不到了。
  • 按钮上的固定文字（「签到」「领取」「确定」）是最好的目标，稳定又好认。

按照脚本里的示范配置，你需要裁出这几张（文件名要一模一样）：

文件名裁什么没有的话
close.png开屏广告/公告右上角的关闭 X删掉这一步
main.png主界面上一个固定不变的标志物，用来确认「确实进游戏了」建议保留，这是防瞎点的安全阀
signin_entry.png每日签到的入口按钮必须有
claim.png「领取」按钮必须有
claim2.png「领取」的另一种样子（有些游戏会随机换）没有就在配置里删掉它
ok.png领奖后弹出的「确定」按钮删掉这一步

裁完可以用菜单第 3 项「试一张模板图现在找不找得到」当场验一验： 它会从相似度 0.95 一路试到 0.70，告诉你这张图配多少合适。

5改 daily-login.js 的配置区

打开 daily-login.js，只改文件开头【配置区】那一段。至少要改这两处：

"游戏包名": "com.yzzg.mdgame",   ← 已预填「暗影紀元」
"横屏": false,                    ← 横屏游戏改成 true

包名已经预先填好「暗影紀元-魔幻冒险之旅」的 （Play 商店页， 2026-08-12 确认）。玩别的游戏就按第 3 步查出来替换掉。横屏还是竖屏你自己看着填。

然后按你自己的游戏流程，把「步骤」那个清单改成实际要做的动作。可以用的步骤类型：

类型做什么什么时候用
点图等这张图出现，出现就点它最常用，绝大多数步骤都是它
任选其一几张图里任何一张出现就点弹窗随机、按钮有多种样子时
点掉所有反复点直到这张图消失连续弹出的领奖框、连续「确定」
等图只等它出现，不点确认「确实进到某个界面了」再往下走
点坐标点固定位置实在裁不出模板图时；建议前一步先用「等图」确认界面
等待纯等几秒加载动画、过场
返回按一次系统返回键退出某个子界面
存档截一张图存起来留证据，事后翻看那一刻的画面

每一步还有个 必须 开关：填 true 表示这步做不成就立刻中止并存下现场截图 （关键步骤用），填 false 表示找不到就跳过继续（可有可无的步骤用，例如开屏广告）。

「必须」这个开关，就是脚本不会瞎点的保证。 找不到图的时候它会等待、重试，等不到就按你的设定中止或跳过—— 它不会因为找不到就随便点一个地方。所以关键步骤一律填 true。

6跑 selftest.js 确认环境正常

运行 selftest.js，它会逐项检查并弹窗告诉你结果：

  • 无障碍服务开了没
  • 截图权限拿到没
  • 截到的是不是真实画面（不是黑屏）
  • 找图功能是否正常——它同时验「找得到」和「找不到时会不会老实说找不到」
  • 模板图能不能读、尺寸对不对、分辨率跟截图时是否一致

全绿再往下走。有红的话弹窗里会直接写清楚是哪一层、怎么修。

7手动跑一次 daily-login.js

第一次一定要在旁边看着它跑完整一遍，别直接设定时。 看它是不是每一步都点对了。跑完可以翻 /sdcard/game-bot/log.txt， 里面每一步的结果都有记录。

没跑成也不要紧：失败时它会自动把当时的屏幕存进 /sdcard/game-bot/shots/，打开看一眼就知道卡在哪个画面了。

8设成每天自动跑

在 AutoX.js 里长按 daily-login.js → 选「定时任务」→ 设成每天某个时间， 比如凌晨 3 点。保存即可。

定时不触发，九成是这两件事： ① 电池优化没关（第 1 步最后那段）；② AutoX.js 被系统「清理」掉了—— 在最近任务列表里给它上锁（下拉卡片有个锁图标）。

脚本内建「一天只跑一次」：万一定时重复触发，第二次会自己退出，不会重复跑。

出问题了怎么查

症状多半是怎么办
完全没反应，日志也没有定时没触发关电池优化、锁住后台，见第 8 步
日志写「无障碍服务没开」系统重启后权限被关重新打开；部分机型每次重启都要重开
日志写「没拿到截图权限」授权框没点手动跑一次，点「立即开始」并勾不再询问
日志写「找不到 xxx.png」模板图问题（最常见）用 capture-helper 第 3 项试找图，按它建议调低「相似度」；还不行就重裁，裁小一点
某天突然全找不到了游戏更新改了界面，或你改过手机「显示大小」重新截图重裁模板。自检会提示分辨率对不上
点是点了但点错地方相似度调得太低往上调（0.9），并把模板图裁得更有辨识度
跑到一半卡住遇到没配置的弹窗看 shots/ 里的失败截图，把那个弹窗加成一步
日志说截到纯色 / 一直停在锁屏手机有密码锁，脚本解不开脚本只能应付「上滑解锁」。有 PIN/图案/指纹锁的话，把这台手机设成免密，或者让它在屏幕本来就亮着的时候跑

想让它顺便发通知给你

配置区里有 TG机器人Token 和 TG聊天ID 两栏，填上之后 每天跑完会发一条 Telegram 消息告诉你成功还是失败。

这两个值是私密的，只填在手机上那一份，不要传回 GitHub 仓库—— 这个仓库是公开的，填进去等于把机器人送人。仓库里有自动检查守着这一条。

换成另一个游戏怎么办

不用改代码，重做一遍第 3～5 步就行：查新游戏的包名、连拍截图、裁新的模板图、 改配置区的步骤清单。想同时管两个游戏，就把 daily-login.js 复制成两份， 各自改配置，模板图分别放在不同文件夹里（把脚本里的 模板目录 那行路径改掉）。

本页与三个脚本都在仓库 game-bot/ 目录下。 脚本改动有 CI 自动检查语法、检查说明书与脚本是否同步、检查私密信息有没有被误提交。
